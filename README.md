# 🚨 Rapid Response System

A real-time, AI-driven application featuring a **Flutter frontend**, **Golang backend**, and **Python AI service**.

---

## 🚀 Getting Started (Local Development)

We use **Docker** and a unified **Makefile** to manage local infrastructure:

- PostgreSQL
- Redis
- RabbitMQ
- MinIO

---

## 📦 Prerequisites

Make sure you have the following installed:

- [Docker Desktop](https://www.docker.com/products/docker-desktop/) or Docker Engine  
- `make` (GNU Make)

---

## ⚙️ Setup Instructions

### 1. Clone the Repository

```bash
git clone https://github.com/Kprateek283/Rapid-Response-System.git
cd Rapid-Response-System
````

---

### 2. Start Infrastructure

```bash
make up
```

This will:

* Automatically create your `.env` file
* Start all required Docker containers in the background

---

### 3. Stop Infrastructure

```bash
make down
```
---

### 4. Clean & Reset (⚠️ Destructive)
```bash
make clean
```
This will:

* Stop all containers
* Remove volumes
* Reset all databases (fresh start)


## Notes

* Prefer `docker compose` (v2) over `docker-compose` (v1)
* Ensure ports used by services are free
* `.env` is auto-generated by the Makefile
